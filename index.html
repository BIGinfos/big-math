📥 Corriger automatiquement un ancien sujet

Dépose ton sujet, BIG-Infos Math le résout

Le sujet est extrait, y compris lorsque le document Word contient une photo ou un scan. Le logiciel détecte les exercices, puis corrige uniquement les questions qu’il reconnaît avec certitude.

Formats acceptés : TXT, HTML, Word (.docx), PDF et images. Le logiciel extrait d’abord le vrai texte du document avant de chercher les exercices. Un fichier Word n’est jamais lu comme un simple texte binaire : son contenu est extrait depuis le XML interne du document.
